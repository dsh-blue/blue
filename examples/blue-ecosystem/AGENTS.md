# `@dsh-blue-example/blue-ecosystem`

Composition-only, opt-in validation bundle. Its six Cordis rows mount the six
runnable ecosystem examples; the user kit is a dependency, not a row. The
module entry owns no product behavior and binds its empty apply hook to the
Cordis Fiber solely for package validation.

Keep this package outside Blue's release set and default bundle. It proves
one-command packed/profile activation but is not an eighth G6 example
scenario.
