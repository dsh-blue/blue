# `@dsh-blue-example/right-inspector`

Interaction example scoped to one consumer Fiber and the host `panes`
registry. It registers one passive right-lane inspector through public wire
nodes and the published user kit. Core owns right-to-bottom degradation,
layout, rendering, and width truth.

The source request and packaged manifest retain their compatible executable
Blue API Beta range; this example is Beta evidence, not a Stable v1 claim.

Keep the package opt-in and outside the product bundle. Its manifest, entry
name, package name, and one-row Cordis patch id/name remain identical.
