# `@dsh-blue/blue-frontend`

English | [中文](README.zh.md)

Renderer-neutral frontend models and services for Blue: transcript facts,
tool presentations, structured actions, locale catalogs, semantic themes, and
notifications.

Models contain no terminal or Harness runtime objects. Canonical
`BlueUiNode` values are compiled only by core. This package has no provider
host and does not adapt native dsh services.
