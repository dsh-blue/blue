# 插件市场

::: info 建设中
插件市场是 Blue 正式发布路线的一部分，目前处于预览阶段、尚未上线。本页将随市场开放同步更新。
:::

## 这里会有什么

- **发现** —— 浏览社区为 Blue 编写的插件：状态栏条目、工具卡片、编辑器增强、全新主题、完整面板；
- **安装** —— 一行 `dsh plugin add` 进入你的 profile，卸载同样一行——Blue 的一切表面都是 patch 行，市场只是让"加一行"变得更简单；
- **发布** —— 你的插件是一个 Cordis 插件 + 一条子路径导出（见[编写 Blue 插件](/plugins/)），发布到 npm 后即可收录进市场目录。

## 在市场上线之前

- 内置增强（bash 模式、贴图、git 状态、todo 面板……）全部随 Blue 本体提供，无需额外安装——见[功能总览](/features/)；
- 想提前接入自己的插件，直接读[编写 Blue 插件](/plugins/)——缝已经全部开放；
- 关注 [GitHub 仓库](https://github.com/dsh-blue/blue)获取市场开放公告。
