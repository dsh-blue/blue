# Submit a plugin

Before submission:

1. ship an ordinary Cordis entry activated by its own `cordis.patch.yml`;
2. list native dsh and Blue UI injections in README;
3. independently install the tarball and verify exports, types, and files;
4. test Fiber unload, Agent/session scope, async abort, and narrow widths;
5. accept real startup and primary workflow in a dedicated Blue profile;
6. state package name, repository, license, version, support matrix, and
   maintainers.

The marketplace PR includes the npm package, repository, short description,
service list, screenshot or recording, verification commands, and acceptance
profile. Marketplace listing does not replace npm publication authorization or
the package's own security review.
